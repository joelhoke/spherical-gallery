Documentation

Bring your own collection.

Two independent packages, shared across JavaScript, Web Components, React, and Next.js. No content service, logo, or font is bundled.

Install and enhance

During review, install the packed .tgz artifacts. After publication:

npm install @joelhoke/spherical-gallery
npm install @joelhoke/mesh-backgrounds # optional
import { createGallery } from '@joelhoke/spherical-gallery'
import '@joelhoke/spherical-gallery/styles.css'

const gallery = createGallery(container, {
  items: [{
    id: 'orbit', title: 'Orbit', alt: 'A blue orbital sculpture',
    poster: '/orbit.jpg',
    destination: { kind: 'link', href: '/work/orbit' }
  }],
  title: 'Work', theme: 'system'
})

Keep real links in your original HTML as a no-JavaScript fallback. Call registerSphericalGallery() explicitly to use <spherical-gallery>; importing never registers global elements.

React and Next.js

'use client'
import { SphericalGallery } from '@joelhoke/spherical-gallery/react'
import '@joelhoke/spherical-gallery/styles.css'

export function Work({ items }) {
  return <SphericalGallery items={items} theme="system" />
}

The server sends a usable Grid, with each real item once. Enhancement follows hydration. Custom card, placeholder, toolbar, and preview slots remain in your React context.

Styling and accessibility

Set --sg-height for a container, or select viewport sizing. Use --sg-background, --sg-color, --sg-font, --sg-display-font, --sg-border, and --sg-accent for your brand.

Arrow keys explore, Home returns to start, and reduced motion keeps Grid. Previews contain focus and restore it on close. Active-only playback stops during motion, offscreen, or in hidden documents.

Backgrounds alone

import { createMeshBackground } from '@joelhoke/mesh-backgrounds'
const mesh = createMeshBackground(hero, {
  seed: 104729, palette: 'twilight', renderer: 'ascii',
  interactive: true
})
mesh.setActive(false) // pixels and phase stay intact
mesh.destroy()

Preview windows and lifecycle

Embedding is explicit and requires a configured origin. A visible ordinary link remains available if framing is blocked. The close/Escape bridge validates both the actual frame window and its configured origin. Password forms and authentication stay in your application.

Destroy imperative controllers when removing them. React and custom elements clean up on unmount/disconnect. Renderer handles must clean up their own resources.
